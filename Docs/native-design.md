# Astra 原生视觉与交互体系

这次改版把界面的重心交还给人物、照片与记录。暖白和墨绿构成阅读空间，香槟金只强调关键动作和收藏层级。系统导航、搜索、表单、照片选择器和地图继续采用原生 SwiftUI / UIKit 行为。

## 视觉规则

| 项目 | 规则 |
| --- | --- |
| 配色 | `Palette` 集中管理深浅模式；正文、次要文字、分隔线和表面均使用语义色 |
| 阅读表面 | 暖白 / 墨色实体卡片，0.5pt 边界，无彩色外发光 |
| 材质 | Liquid Glass 用于地图悬浮控件和系统导航；降低透明度时退化为实体表面 |
| 字体 | 系统正文保证中文可读性，系统衬线标题与数字形成层级；不依赖网络字体 |
| 间距 | 页面边距 20pt，模块间距 24pt；主要圆角 24pt，动作圆角 16pt |
| 宽屏 | 滚动内容最大宽度 840pt，图鉴和成就网格按宽度换列 |
| 交互 | 主要按钮 50pt，筛选胶囊至少 44pt；按压反馈尊重系统「减弱动态效果」 |
| 装饰 | 原生矢量轨道标记，减少重复的水印、渐变和嵌套卡片 |

## 页面结构

- **星图**：近况总览 → 记一笔 → 最近人物 / 待处理 / 最近记录 → 图鉴、统计、地图、成就入口。最近记录直接进入对应记录编辑器。
- **名册**：常驻搜索 → 图鉴与排行 → 联系周期与分组名册。搜索/筛选生效时提供明确的重置操作，联系周期推荐不会混入筛选结果。
- **时间线**：记录数量与统计入口 → 结果范围 → 按日记录。近 6 个月趋势按需展开；删除记录先确认。
- **档案**：头像、代号与地点 → 状态 → 简明数据 → 记录动作 → 照片、评分、线索与时间线。
- **图鉴**：轻量标题 → 当日回忆 → 可排序的照片网格。隐藏代号时保留相册打开限制。
- **表单**：新建记录先显示人物、结果、日期、地点、保护情况与备注；玩法、感受、照片和跟进由「补充相处细节」展开。编辑既有记录自动展开。新建档案的基础信息优先，其他信息用「完善档案」展开。
- **设置与锁屏**：统一品牌标记和阅读表面；隐私项置前，后台遮罩使用不透明底色。

收起可选字段不会修改字段值；保存、导入导出、媒体引用、成就计算及既有数据键保持兼容。

## 无障碍

使用系统 Dynamic Type，标题/正文不依赖固定字号。首页指标、档案指标、图鉴、成就和评分网格支持大字体重排。人名隐藏时改为占位符，VoiceOver 不读出代号；头像在隐藏状态下整体遮糊。颜色之外继续使用文字、符号和选中语义表达状态。

## 原生验证

`Astra-UIReview` scheme 包含既有单元测试与 `NativeRedesignUITests`。GitHub Actions 的 `Native UI review` 在 PR 中运行，用原生模拟器导出截图附件和日志。

```bash
xcodegen generate
xcodebuild test -project Astra.xcodeproj -scheme Astra-UIReview \
  -destination 'platform=iOS Simulator,name=iPhone 16,OS=latest' \
  -resultBundlePath UIReview.xcresult CODE_SIGNING_ALLOWED=NO
xcrun xcresulttool export attachments --path UIReview.xcresult --output-path ui-screenshots
```

iPhone 执行完整测试；iPad 执行主要页面导航与截图检查。颜色对比度测试验证深浅模式下主要正文与操作色均达到 4.5:1。测试场景覆盖深浅模式、放大字体、空数据、隐藏代号、搜索无结果恢复、记录保存、地图与图鉴导航。截图中的人物和记录全部是 Debug 专用虚构样例，使用独立的 UserDefaults suite；Release 不包含样例初始化代码。

合并前仍应在目标 iPhone / iPad 上检查横屏、VoiceOver 阅读顺序、系统触感、真实照片以及 iOS 18 的材质回退。CI 结果与截图以 PR 的具体提交为准。

成就与升阶提示依次呈现，浮层期间关闭背景交互；大字体下首页记录按钮移到指标之前。搜索激活时名册隐藏介绍和快捷入口，重置会退出搜索并收起键盘。
