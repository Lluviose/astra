# Astra 原生设计体系

Astra 的定位是私人后宫收藏与战绩陈列。照片负责吸引浏览，记录负责积累，殿堂负责呈现收藏的分量。功能与心理体验见 [欲望、收藏与战绩循环](desire-achievement-loop.md)。

## 三个主页面

| 主页面 | 第一眼 | 核心操作 | 次级内容 |
| --- | --- | --- | --- |
| 后宫 | 收藏数量、今日回味大封面 | 点封面翻私藏；打开她的档案 | 偏爱筛选、收藏排序、全部名册 |
| 战绩 | 时间顺序中的记录 | 快速记录、搜索、筛选 | 指定人物 / 时间范围、跟进完成与撤销 |
| 殿堂 | 封号、后宫与领地总量 | 欣赏个人巅峰、定制身份 | 勋章、传奇后宫、版图、私密排行、战绩分析、战绩卡 |

独立的总览首页退出主导航，设置移入工具栏。记录保存后的全屏结算退出，改为轻提示；勋章与升阶机制保留，进入殿堂可查看新进展。

## 视觉语言

- 暖白用于阅读，深墨与酒红用于收藏封面，旧金强调层级与身份。深浅模式使用语义色，金色正文在浅底上使用足够深的色值。
- 人物照片采用大封面与竖向网格，提供无照片时的字印占位。没有真实照片时不填充虚构人物照。
- 正文使用系统字体，标题与重要数字使用系统衬线字体。圆角、细边界与间距保持统一，不叠加彩色光晕。
- 原生导航、搜索、表单、照片选择器和地图继续遵循系统行为。Liquid Glass 集中用于悬浮地图控件。
- 页面边距 20pt，宽屏内容上限 840pt；网格随宽度换列，大字体时重排。选择控件至少 44pt，主要动作至少 50pt。

## 核心流程

首次记录从人物代号开始，地点可以留空；已有一位活跃人物时直接进入记录，多位时先选择，也可当场新建。取消建档不会生成空记录。表单先显示结果、时间、地点、保护情况和备注，可选细节按需展开，收起不清除输入。

人物档案分为战绩、画像、私藏。偏爱使用原有置顶字段；评分可单独编辑并保存或取消。后宫只收录有亲密记录的人，归档不抹掉收藏；完整名册保留其他人物。今日回味优先从偏爱人物中按日轮换，有私藏时直接进入照片浏览，否则进入档案。

搜索、人物、时间和结果条件取交集。重置清除条件并收起键盘；跟进可以直接完成并撤销。记录删除先确认。殿堂保留原有称号、传奇、领地、成就与匿名战绩卡的数据计算。

## 验证

`Astra-UIReview` scheme 运行单元测试与原生 UI 测试。iPhone 执行完整流程，iPad 执行主要页面导航与截图检查；工作流导出截图和日志。

```bash
xcodegen generate
xcodebuild test -project Astra.xcodeproj -scheme Astra-UIReview \
  -destination 'platform=iOS Simulator,name=iPhone 16,OS=latest' \
  -resultBundlePath UIReview.xcresult CODE_SIGNING_ALLOWED=NO
```

测试覆盖颜色对比度、日期边界、组合筛选、首次记录、单人物直达、新建人物衔接、跟进完成与撤销，以及原有存储、备份、媒体和成就逻辑。截图中的人物与记录是 Debug 专用虚构样例，使用独立 UserDefaults，Release 不包含样例初始化代码。

模拟器结果以 PR 对应提交为准；真实照片、设备触感、VoiceOver 完整阅读顺序以及 iOS 18 材质回退仍需真机验收。
