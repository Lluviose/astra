# 人物与约炮记录

## 入口

- 记已有的人：选择人物 → 记录结果；可用代号、联系方式、标签或地点搜索。
- 记新的人：选人页点「新增人物，接着记这次」→ 保存人物 → 自动打开这次记录。名册为空时直接建档。
- 只新增人物：直接打开人物表单，不再先弹地点选择器。
- 从人物详情进入：直接带入人物与常驻地点，记录页明确要求核对实际地点。
- 取消人物建档不创建人物或记录；人物保存后取消约炮记录，只保留已保存的人物。

## 人物表单

使用系统 NavigationStack、Form、分段选择器和底部工具栏，分为三页，任何一页都可保存。

| 页 | 内容 |
| --- | --- |
| 基本资料 | 代号、头像、联系方式、常驻城市 / 国家、认识渠道、认识日期、关系阶段；年龄、身材、生日、职业按需展开 |
| 约法与标签 | 关系期待、已沟通的规矩、安全备忘；7 组人物标签、自定义标签、六维评分、联系提醒和备注 |
| 照片 | 人物资料照和艳照私藏分开添加、分开保存 |

新建人物不预填城市、不预打分，关系从「刚认识」开始；选择有效地点后即可保存，代号可留空。认识渠道有线上和线下 17 个快捷选项，也能自行输入。约法的快捷短语只切换完整文本片段，其余自由备注保留。人物标签按长相与打扮、身材、床上印象、关系与联系、时间与距离、生活习惯、已沟通的偏好分类；已有自定义标签仍可用。

## 约炮表单

只有「上床了 / 没上床」两种结果，统计口径保持不变。对象、结果、时间、城市或国家构成最小记录，其他字段可跳过。

| 页 | 上床了 | 没上床 |
| --- | --- | --- |
| 结果 | 对象、结果、时间、地点、场所类型、场所备注 | 同左，另选进展和原因 |
| 细节 | 行为 → 高潮与射精 → 戴套与其他防护 → 边界与状态 → 感受 → 花费与备注 → 照片 | 感受 → 花费与备注 → 照片 |
| 跟进 | 保存摘要、主动勾选后续事项、日期、完成状态 | 保存摘要、联系 / 再约 / 账号 / 其他事项 |

- 场所类型有 12 种，另有「未记录」；它与城市、场所备注分开存，不把“在哪一步没成”写进地点。
- 没上床进展有聊天、已约时间、取消、没来、见面、接吻拥抱、一起过夜，另有「未记录」。14 个原因可多选；不把没上床一律当作失败。
- 行为分成接吻与手上动作、口交、性交、姿势、场景、其他行为；原有行为值不变。
- 高潮与射精分成她的高潮、我的射精、次数与其他；加入没高潮、不确定、没射精，互斥项选中时取消矛盾项，多轮仍可选多种收尾。
- 防护可选未记录、全程戴套、部分戴套、无套、无对应行为；不根据收尾自动推断戴套情况。
- 复用上次只替换行为和收尾，已有细节时先确认；本次日期、地点、花费、防护与跟进都独立填写。
- 切页或临时切换结果不清空草稿。保存时才按最终结果清理不适用字段，保留照片与共有备注。
- 花费支持小数；空值表示没记录，0 表示明确没有花费；非法值阻止保存并提供修改入口。

## 原生界面与动效

固定步骤栏位于系统导航下方，底部始终提供上一步、下一步或保存；表单使用系统分组背景，无网页式大卡片与投影叠加。

切页使用前进 / 返回方向不同的弹簧位移、透明度和轻模糊过渡；标题图标通过 SF Symbols 替换，进度同步变化。选择按钮有按压回弹、勾选替换与背景过渡，点击区域至少 44pt。切页先收起键盘；Form 换页重置滚动位置，草稿保留在父视图。减弱动态效果开启后仅短淡入，不做位移、模糊、缩放或符号变形；辅助功能大字体把分段选择器换成系统菜单。

## 存储、时间线与验证

`Encounter` 增加 `venueCategory`、`missedProgress`、`missedReasons`。旧备份缺失时分别回退未记录、未记录、空集合，不猜测旧备注的含义。原有存储键、人物自由文本、标签和媒体引用保持兼容。新版本备份含新增枚举值时不保证旧版应用可导入。

时间线与人物详情展示场所和没上床摘要，并支持用场所类别、进展、原因搜索。地图仍按城市 / 国家聚合，两种结果的统计口径不变。

自动测试覆盖旧记录解码、新字段与小数金额往返、结果清理、模板复用边界、高潮互斥、建档取消、从选人页新增、保存人物后继续记录。PR validation 工作流在 iOS 模拟器执行测试；原有 main 的 IPA 工作流保持不变。

手工体验检查：小屏和大字体、深浅色、快速往返切页、输入时换页、照片未保存取消、减弱动态效果、从人物保存接入约炮表单。
