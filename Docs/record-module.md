# 人物与约炮记录

## 入口

- 记已有的人：选择人物 → 记录结果；可用代号、联系方式、标签或地点搜索。
- 记新的人：选人页点「新增人物，接着记这次」→ 保存人物 → 自动打开这次记录。名册为空时直接建档。
- 只新增人物：直接打开人物表单，不再先弹地点选择器。
- 从人物详情进入：直接带入人物与常驻地点，记录页明确要求核对实际地点。
- 取消人物建档不创建人物或记录；人物保存后取消约炮记录，只保留已保存的人物。

## 人物表单

使用系统 NavigationStack、Form、分段选择器和底部工具栏，分为三页，任何一页都可保存。

| 页 | 内容 |
| --- | --- |
| 基本资料 | 代号、头像、联系方式、常驻城市 / 国家、认识渠道、认识日期、关系阶段；年龄、身材、生日、职业按需展开 |
| 偏好与约法 | 见她之前看一眼（她在床上喜欢什么、怎么约她最顺）、关系期待、已沟通的规矩、安全备忘；7 组人物标签、自定义标签、六维评分、联系提醒和备注 |
| 照片 | 人物资料照和艳照私藏分开添加、分开保存，照片和视频都能选；已存的只读预览，待保存的缩略图可单张删除 |

新建人物不预填城市、不预打分，关系从「刚认识」开始；选择有效地点后即可保存，代号可留空。认识渠道有线上和线下 17 个快捷选项，也能自行输入。「她在床上喜欢什么」有 18 条快捷短语（节奏、敏感点、姿势、灯光、主导），「怎么约她最顺」有 16 条（开口方式、时间窗口、地点习惯）；快捷短语只切换完整文本片段，其余自由备注保留。人物标签按长相与打扮、身材、床上印象、关系与联系、时间与距离、生活习惯、已沟通的偏好分类；已有自定义标签仍可用。

`Companion` 新增 `turnOns`、`approachNotes` 两个字符串字段，旧备份缺失时回退空串。`hasPlaybook` 表示五条私密备忘里有任何一条非空；`daysKnown(asOf:)` 按日历天数算认识了多久。

## 约炮表单

只有「上床了 / 没上床」两种结果，统计口径保持不变。对象、结果、时间、城市或国家构成最小记录，其他字段可跳过。

| 页 | 上床了 | 没上床 |
| --- | --- | --- |
| 结果 | 对象（含她的床上偏好提示）、两张结果大卡、快捷时间 + 具体时间、城市 / 国家、场所芯片、场所备注 | 同左，另选进展和原因 |
| 细节 | 节奏（谁主动 / 几轮 / 多久）→ 行为 → 高潮与射精 → 做完之后 → 戴套与其他防护 → 边界与状态 → 感受与还想不想 → 氛围 → 花费、谁买单、花在哪与备注 → 照片 | 感受 → 还想不想 → 氛围 → 花费、谁买单、花在哪与备注 → 照片 |
| 跟进 | 保存摘要（含节奏、事后、氛围、花费、买单、照片数）、主动勾选后续事项、日期、完成状态 | 保存摘要、联系 / 再约 / 账号 / 还东西 / 发照片 / 礼物 / 其他事项 |

- 结果大卡：选中的一张实色，另一张是 Liquid Glass（iOS 18 为 Material），放在 `GlassEffectContainer` 里。
- 快捷时间有刚刚、昨晚（23:00）、今早（08:00，不超过现在）、昨天下午（15:00）、前天晚上（22:00），只是把 DatePicker 定位到常见时刻，随后仍可细调；命中某档时该芯片亮起，否则全部不亮。
- 场所类型 12 种做成芯片带图标，再点一次取消回到「未记录」；它与城市、场所备注分开存，不把“在哪一步没成”写进地点。
- 没上床进展有聊天、已约时间、取消、没来、见面、接吻拥抱、一起过夜，做成单选芯片；14 个原因可多选；不把没上床一律当作失败。
- 节奏：谁主动（我 / 她 / 一拍即合）、几轮（1 ～ 5 轮以上，存 1...9）、多久（10 分钟内到 2 小时以上七档，存分钟数 1...720）。选 2 轮以上会自动勾上行为里的「多轮」，选 1 轮会取消它；先勾「多轮」且没选轮数时默认记 2 轮。导入的非档位分钟数照样显示。
- 行为分成接吻与手上动作、口、性交、姿势、节奏、场景、情趣与玩法七组，每组标题显示已选数量；共 45 项，含足交、舔后庭、玩胸、互相用手、深喉、背对着骑、趴着后入、面对面坐着、架起腿、沙发 / 桌上、速战速决、慢慢磨、晨炮、过夜、打屁股、角色扮演、内衣丝袜不脱、眼罩 / 捆绑、对着镜子、拉头发 / 掐腰；原有行为值不变。
- 高潮与射精分成她的高潮、我的射精、次数与其他，共 20 项；「她潮吹了」不和「她没高潮 / 不确定」互斥，「她先到的」「一起到的」和高潮了同组处理，「一起到的」同时算作我射了。射的位置新增背上 / 屁股、嘴边 / 脸颊、口爆吐出来。没高潮、不确定、没射精互斥项选中时取消矛盾项，多轮仍可选多种收尾。
- 防护可选未记录、全程戴套、部分戴套、无套、无对应行为；不根据收尾自动推断戴套情况。具体方式新增 PEP、事后紧急避孕、近期检测过；当时状态新增欲火旺、有点紧张、只是寂寞。
- 做完之后：抱着躺、一起睡到天亮、一起洗、聊了很久、一起吃、一起抽烟、我做完就走、她做完就走、第二天早上又来了一次、送了 / 收了小礼物。我走 / 她走互斥，和过夜、早上再来互斥；没上床时清空。
- 氛围：激情、温柔、玩闹、放得开、有点尴尬、匆忙、微醺、例行公事，单选，再点取消；上床了、没上床都能记，用于回味，不参与评分。
- 谁买单：我 / 她 / AA / 没花钱，单选；花在哪：房费、吃饭、喝酒、打车、礼物 / 红包、套 / 用品、票、其他，多选。选「没花钱」会清掉金额和项目。金额仍是独立字段，可以只记项目不记钱。
- 还想不想做成芯片（还想约 / 看情况 / 不再约），再点取消回到未决定。
- 跟进事项：上床了可勾全部 11 项；没上床只能勾回个消息、再约一次、账号有点不对、还她东西、发她照片、送个礼物、其他，由 `FollowUpKind.missedCases` 统一定义，保存时按结果清理。
- 复用上次只替换行为和收尾，已有细节时先确认；本次日期、地点、节奏、花费、防护与跟进都独立填写。
- 切页或临时切换结果不清空草稿。保存时才按最终结果清理不适用字段（含节奏三项），保留照片与共有备注。
- 花费支持小数；空值表示没记录，0 表示明确没有花费；非法值阻止保存并提供修改入口。

## 人物档案

- 封面：头像、代号、阶段、地点、「认识 X 天 · 第 Y 天上床」（没记认识日期时显示第一次的相对日期）、综合分环（有分才显示）、四格数字、两个结果按钮（iOS 26 玻璃）。
- 见她之前看一眼：她在床上喜欢、怎么约她最顺、她想怎么约、她说过不行的、安全备忘，任一非空才出现，位于战绩之前。
- 和她的战绩：第一次上床、上床率、平均间隔、平均多久、平均几轮、谁更主动、最常做、怎么收的、做完之后、常见氛围、套、花费合计、谁买单、身体感受、常在、最爽的一次（身体感受最高、同分取最近，点开直接编辑那条）。
- 基本线索：联系方式点一下复制到剪贴板，图标变勾 1.6 秒。
- 时间线行：节奏摘要「她主动 · 2 轮 · 45 分钟」排在行为摘要前，其后是行为、收尾、事后摘要；第二行显示场所、套、照片数、花费、谁买单和氛围。
- 档案里的记录行右滑一步「完成跟进」，左滑删除前先确认并提示会一起删掉几张照片。

## 原生界面与动效

固定步骤栏位于系统导航下方，底部始终提供上一步、下一步或保存；表单使用系统分组背景，无网页式大卡片与投影叠加。

切页使用前进 / 返回方向不同的弹簧位移、透明度和轻模糊过渡；标题图标通过 SF Symbols 替换，进度同步变化。选择按钮有按压回弹、勾选替换与背景过渡，点击区域至少 44pt；分组标题右侧的已选数量用 numericText 过渡。切页先收起键盘；Form 换页重置滚动位置，草稿保留在父视图。减弱动态效果开启后仅短淡入，不做位移、模糊、缩放或符号变形；辅助功能大字体把分段选择器换成系统菜单。

Liquid Glass 全部收敛在 `Design/LiquidGlass.swift`：`LiquidGlass.isAvailable` 供需要在玻璃与实色之间切排版的视图判断；`heroGlass` 给深色封面上的按钮；`glassActionStyle` 给相册 / 拍照 / 去掉照片按钮；`OutcomeCard` 未选中态用 `liquidGlass`。iOS 18 分别降级为白色半透明描边、胶囊实色和 Material。

## 照片与视频

- 存储：`MediaStore` 按扩展名区分种类，图片一律 `.jpg`（内容可以是 PNG 原图），视频保留来源的 `.mov` / `.mp4`；同一 ID 只对应一个文件，重写会先清掉旧扩展名。`kind(id:)`、`isVideo(id:)`、`videoURL(id:)`、`fileExtension(id:)` 供界面判断。
- 原图原则不变：图片按原始字节保存，`image(id:)` 读原图不降采样；视频原样落盘不转码。`thumbnail(id:maxPixel:)` 只给列表和网格生成降采样副本（图片走 ImageIO，视频取首帧），进内存缓存，不写回磁盘。
- 导入：相册选择器允许图片和视频，视频按文件拷贝进沙盒，不整段读进内存；相机可拍照或拍视频，拍视频需要麦克风权限。头像只收图片。
- 展示：缩略图上视频显示时长角标；档案相册用三列九宫格，超过 9 个可展开，长按删除；封面只选图片。查看器左右分页，图片双指缩放 1～5 倍、双击放大，视频用系统播放器，翻页即暂停。
- 备份：`BackupPayload` v5 新增 `mediaExtensions`，只列非图片媒体的扩展名；旧备份没有这一项，全部按图片还原。扩展名不是 mov / mp4 的备份会被拒绝。
- 设置页显示照片 / 视频合计占用空间。

## 存储、时间线与验证

`Encounter` 增加 `initiator`、`rounds`、`durationMinutes`，加上此前的 `venueCategory`、`missedProgress`、`missedReasons`。旧备份缺失时分别回退未记录、nil、nil，不猜测旧备注的含义；轮数收进 1...9、分钟收进 1...720，非法值视为没记。本轮再增 `mood`、`afterglow`、`payer`、`costItems` 与 `updatedAt`：前四项缺失时回退未记录 / 空集合，`updatedAt` 缺失时回退为发生时间。原有存储键、人物自由文本、标签和媒体引用保持兼容。新版本备份含新增枚举值时不保证旧版应用可导入。

`AppState.upsert(_ encounter:)` 每次保存都盖上 `updatedAt`；合并导入时同一 ID 的记录以 `updatedAt` 较新的一份为准，导入摘要新增「更新 N 条记录」。`AppState.setFollowUpDone(_:encounterID:)` 供首页、时间线、档案里的右滑 / 长按一步完成或重新待办，没勾过事项的记录不会被改动。

`EncounterInsights` 新增 `averageDurationMinutes`、`averageRounds`、`initiatorCounts` / `dominantInitiator`、`firstHookupDate`、`bestHookupID`、`topAfterglow`，全部只看「上床了」的记录；`moodCounts` / `dominantMood`、`payerCounts` / `myTreatRate`、`costItemCounts` 两种结果都算。

时间线与人物详情展示场所、节奏、事后、氛围、买单和没上床摘要，并支持用场所类别、进展、原因、节奏、事后、氛围、买单、跟进事项、安全备忘和人物标签搜索。时间线删除前弹确认并提示照片数，长按可再记她一笔、打开档案、勾完 / 重开跟进。地图仍按城市 / 国家聚合，两种结果的统计口径不变。

自动测试覆盖旧记录解码、新字段与小数金额往返、氛围 / 事后 / 买单往返与旧记录回退、没上床清空事后但保留氛围与买单、没上床可勾事项集合、新收尾项的互斥规则、跟进完成辅助方法、`updatedAt` 回退、列表一步勾完跟进、按 `updatedAt` 合并导入、保存盖时间戳、氛围 / 买单 / 事后统计、节奏字段归一化与没上床清理、时长文案、行为与收尾分组完整性、潮吹不与不确定互斥、人物偏好字段解码、认识天数、快捷时间不指向未来、结果清理、模板复用边界、高潮互斥、洞察里的节奏平均值与里程碑、建档取消、从选人页新增、保存人物后继续记录。PR validation 工作流在 iOS 模拟器执行测试；原有 main 的 IPA 工作流保持不变。

手工体验检查：小屏和大字体、深浅色、快速往返切页、输入时换页、照片未保存取消、减弱动态效果、从人物保存接入约炮表单、iOS 18 与 iOS 26 各看一遍结果大卡与封面按钮。
