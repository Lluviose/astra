# 结果记录与时间线

## 定位

记录模块只回答一个最直接的问题：这次上床了，还是没上床。聊天、吃饭、见面、过夜不再作为独立事件，避免同一次经历被拆成多条含义模糊的记录。

## 数据结构

每条记录的必选结果只有两种：

- **上床了**：计入上床次数，可继续记录实际行为、防护、感受、照片和后续事项。
- **没上床**：计入未成结果，保留时间、城市、地点 / 阶段、情绪、原因备注和下一步。

对象、时间、结果和城市构成最小记录。其余字段均可跳过或稍后补充。

## 交互结构

```text
结果（默认可直接保存）
├─ 上床了 / 没上床
├─ 对象 / 时间 / 城市 / 地点
├─ 上床了
│  ├─ 做了什么与高潮细节
│  ├─ 边界与当时状态
│  ├─ 防护与健康
│  └─ 身体 / 情绪感受
├─ 没上床
│  ├─ 情绪感受
│  └─ 原因与下一步
├─ 照片
└─ 用户主动创建的后续事项
```

对象详情与首页都只提供两个结果入口。编辑器允许修改结果；改为“没上床”时会清除只属于性行为的字段，避免把防护或姿势误挂到失败记录上。

## 时间线

时间线是记录的主浏览入口：

- 按自然日倒序分组，行内显示具体时间、对象、城市和结果。
- 支持“全部 / 上床 / 没上 / 跟进”筛选。
- 近六个月用双柱并列展示两种结果。
- 顶部展示累计上床、没上床、涉及城市和上床率；所有统计只在本机显示。

## 地图

地图按每条记录实际选择的城市聚合，而不是只按对象常驻城市。没有结果但已建档的城市仍可作为待推进猎场显示。

- 全部图层显示所有已建档或有记录的城市。
- 上床图层只显示发生过成功结果的城市。
- 没上图层只显示出现过未成结果的城市。
- 城市面板显示上床 / 没上数量、最近结果、当地时间线和相关对象。
- 城市粒度来自内置目录，不请求定位，也不保存精确坐标。

## 安全与隐私

- 只记录成年人之间自愿、知情且可随时撤回的行为。
- 防护字段记录实际方式，不计算“安全分”，也不给对象贴风险标签。
- 待跟进只有用户主动勾选后才出现。
- 代号、照片、备注和结果都只保存在本机沙盒，可随设备 iCloud Backup 恢复。
- 地图只显示城市级足迹；MapKit 只负责底图。
