# 欲望与成就体验循环

## 产品目标

星图不是公开战绩榜，而是成年用户的私密回忆册。欲望感来自期待、回味和具体细节；成就感来自六维评分、私人排名和自己留下的轨迹，所有比较只在用户本机发生。

核心循环：

```text
想起一个人 → 打开焦点 / 档案 → 发生并记录 → 获得即时反馈 → 看见下一枚目标 → 再次回味
```

## 本轮落地

- **今晚焦点**：首页根据用户主动置顶、相处阶段、已有互动、综合评分和最近联系选出一个焦点。它只整理已记录事实，不计算「成功率」或替对方推断意愿。
- **六维私密评分**：颜值、身材、床上默契、主动感、欲望值、回味欲用 0–10 滑杆记录；快速预设和分段触感让建档更像给一本私人图鉴落笔。
- **对象排行榜**：综合、欲望、床上默契、回味欲和约成次数五条榜单，可切换前三名与完整名次，不对外分享。
- **明确身体资料**：胸部尺码拆成下胸围与 AA–K 罩杯，组合显示为 `75D`，避免模糊的“小 / 中 / 大”。
- **照片分仓**：头像封面、人物资料照、艳照私藏和单次约会照片各自归位；只有艳照进入私藏成就统计。
- **系统恢复**：清除旧版本的排除标记，全部持久化用户数据（档案、设置和照片）都允许进入设备 iCloud Backup。
- **一步记下进展 / 战果**：焦点已经确定对象时，暧昧前打开聊天记录，准炮友及之后打开约成记录，减少一次选择，同时保留完整的边界、防护和跟进字段。
- **快要点亮**：未解锁成就按「已有进度 → 完成比例 → 剩余数量」排序，让下一步具体可见；风险升级条目不进入主动提示，完整章节仍保持原目录顺序。
- **克制的刺激**：深夜紫、莓红、进度环与分层触感制造私密感；照片不会在首页自动裸露，代号遮罩继续生效。

## 下一阶段优先级

1. **事后余温**：保存记录后展示一张 3 秒可关闭的小结，只呈现本次类型、照片数、双方边界备忘和新点亮成就；不自动分享。
2. **主动回味**：增加需长按揭示的「随机一页」，从用户已保存的照片和文字中抽取一段回忆；默认模糊，后台永不显示。
3. **个人最佳**：展示「本月比自己的上月多写了几页」「连续几个月有记录」等个人轨迹，与对象私密排行并列但不对外公开。
4. **想要清单**：让用户记录自己想尝试、已沟通、暂不考虑三种状态；只有双方已明确聊过的事项才能进入待尝试，不把幻想当许可。
5. **语言强度**：提供克制 / 直白两档本地文案偏好，让刺激程度由用户选择，锁屏、通知和分享文案始终保持中性。

## 成功标准与红线

成功标准以本机可观察的体验为主：从首页到开始记录不超过一次点击；用户能说清下一枚目标是什么；隐藏代号时首页不暴露姓名或照片；记录完成后仍能找到安全与跟进信息。

不会做：公开榜单或分享卡、基于回复速度的约成预测、未经主动揭示的艳照预览、默认敏感通知，以及用连续奖励鼓励无套或其他风险行为。风险事实可以被记录和回看，但不进入主动催促位。
