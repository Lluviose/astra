# 私人后宫：欲望、收藏与身份感

## 产品判断

目标用户打开 Astra 的动机不止是记账。他也想看见自己偏爱的女人、回味私藏、确认个人战绩，并欣赏一份逐渐丰富的后宫。这是本轮产品设计的工作假设，不是对所有男性的研究结论。

界面应让三个满足互相连接：照片带来浏览欲，真实记录带来收藏的分量，封号与纪录提供身份感。快速记录是支撑这套体验的工具。

## 满足与功能的对应

| 用户想获得的满足 | 产品设计 | 本轮实现 |
| --- | --- | --- |
| 想打开看看她 | 大封面、稳定的今日回味、一次进入私藏 | 后宫首页优先偏爱人物，按日轮换；照片直达 |
| 这是我建立的后宫 | 收藏有门槛，也有可辨认的层级 | 亲密记录进入后宫；初猎、回头、王牌、传奇保留 |
| 她在我的偏好里有位置 | 自己评定与排列，而不是系统替用户下判断 | 偏爱筛选、欲望排序、六维画像与私密排行 |
| 我积累得越来越多 | 看得见变化与巅峰，不必每次看完整报表 | 殿堂身份卡、个人纪录、勋章陈列与领地 |
| 这份陈列属于我 | 能定制，又与实际积累相连 | 已解锁封号、三种陈列风格与王都 |
| 想快速留下刚发生的事 | 少选项、少来回、可事后补充 | 人物优先、单人物直达、可选细节展开、轻量保存反馈 |
| 想继续回味或约见 | 从收藏回到人物与具体记录 | 档案分为战绩、画像、私藏；跟进可直接完成与撤销 |

## 高水平设计靠什么

**人物的存在感。** 后宫页给照片足够面积，文字只留下代号、层级与次数。全部名册和评分放到更适合检索与比较的位置，避免照片被密集指标淹没。

**稀疏的身份符号。** 金色、冠饰与封号集中在殿堂和收藏等级，配合深墨、酒红、细边界与衬线数字。平常操作使用安静的实体表面，层级符号因而有分量。

**私人陈列感。** 信息架构是后宫、战绩、殿堂。没有额外的总览首页，也没有公开信息流。空收藏提供明确的开篇动作，已有收藏以今日回味和偏爱选择降低寻找成本。

**有积累感的反馈。** 保存后轻提示，不强迫处理多个结算弹层；进入殿堂能看到更新的身份、勋章与纪录。称号、地点和人物层级来自已有记录，不通过虚构数字营造繁荣。

## 本轮保留、重做与删除

保留后宫门槛、评分、排行、称号、传奇、领地、成就、匿名战绩卡与私密媒体分仓。重做后宫首屏、殿堂主陈列、人物档案导航、首次记录和组合筛选。删除重复的总览首页、独立设置标签页、全屏奖励与升阶弹窗，以及必须先选择城市的建档步骤。

## 验收标准

1. 进入后宫即可看到收藏身份与一个值得打开的封面；有私藏时一次点击进入照片。
2. 一位活跃人物时，记录入口直接打开编辑器；新用户可以不填城市完成第一篇。
3. 人物画像中的评分、偏爱和私藏有明确入口，修改与取消都有确定结果。
4. 保存后仍能立即浏览与搜索，殿堂正确反映新增记录。
5. 深浅模式、小屏和大字体下可阅读、可操作；隐藏状态下代号与照片同步遮蔽。
