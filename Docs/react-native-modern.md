# Astra 现代版设计与架构

用户要求使用 React Native 重设计，开发阶段不需要备份或历史迁移。本版采用 Expo / TypeScript / SQLite，独立入口为 `mobile/`。

## 视觉方向

浅灰白背景、石墨色文字、电光蓝强调。中文标题与正文以系统无衬线字呈现，弱化英文装饰、皇冠、金边和大面积渐变。后宫是照片与文字的画册布局，战绩是连续时间线，殿堂通过单一深色统计区、实数图表和里程碑表达积累。照片信息放在图片外，保持画面完整。

## 交互与结构

三个主标签为后宫、战绩、殿堂。底部新增按钮直接进入记录；人物不足时可当场建档。详情导航使用原生 Stack，记录与人物编辑使用模态流程。页面通过 TypeScript 领域函数校验变更，再通过串行写入队列存入 SQLite 事务，成功后更新状态。

设计变量和基本组件统一定义在 `src/design/ui.tsx`。宽屏使用双栏，手机保持单列；操作目标至少 44pt。页面允许滚动，照片有无、空记录、长备注和隐藏状态均有专门呈现。

## 本轮交付边界

交付可运行的全新版本和主要功能闭环。旧版 SwiftUI 工程留在原位置作参考；本轮不迁移其数据库、备份、全量评级或成就规则。新版本使用独立 bundle identifier，正式切换生产入口属于后续发布工作。

正常构建从空白状态启动；示例构建采用单独数据库并标注示例。示例照片和人物全部虚构。原生地图、认证、照片选择与后台保护需要在 iOS 运行环境验收，网页预览不替代这些能力。
